本步是原生二进制逆向（ELF/PE/Mach-O/WASM）。以下是可选方法参考，按证据选择、允许跳步；已有信息无需重复获取。原始工具输出已自动保存，重要结论、依据和反证写回图即可，不用整段抄写命令输出。

1. 确认文件：file、sha256sum 对照 manifest；readelf -h（PE 用 objdump -x）拿架构、入口、节区。checksec 记录 NX/PIE/Canary/RELRO，即使不做利用也要写进 observation。区头损坏不影响执行：readelf -S 报错就改用 readelf -l，数据常附在最后一个区之后。
2. 静态粗读：strings -a -n 4 找 flag 格式、密码、可疑路径；readelf -s / objdump -t 看符号（stripped 就 r2 的 aaaa）；rabin2 -I -E -S 快速汇总。导入表异常干净 = 动态加载嫌疑，转 gdb 断 dlopen/dlsym 抓 API。Go 的字符串是 {ptr,len} 不 NUL 结尾，strings 会漏一半，go version -m 还能看到 -X 注入值；Rust 先 grep "panicked at" 拿源码路径行号。
3. 反汇编定位主逻辑：r2 -A -c 'afl; s main; pdf' 或 objdump -d -M intel。先找输入校验函数（strcmp、memcmp、scanf/fgets 之后的判断），再沿 xrefs 反推正确输入的约束。常量识别算法：0x67452301=MD5、0x6A09E667=SHA-256、63 7C 77 7B=AES S-box、0x9E3779B9=TEA——知名常量可能被复用，先验证再下结论。
4. 动态验证与直取：样本只能在容器里跑（异架构用 qemu-x86_64 等）。断点下在最终比较指令处，输入任意正确长度字符串，x/s 读比较另一端常直接拿到 flag；有多个比较点时断最后一个（前面的可能是 decoy）。更快一档：以 input[i]=i 为输入跑一遍，记录每次比较的 ZF，置位处的比较值即该位正确字符。
5. LD_PRELOAD 武器化（gcc 现编 .so）：hook memcmp 返回匹配字节数，整体比较变逐字节 oracle；hook EVP_CipherInit_ex 直接打印 AES key/iv；冻结 time()/rand() 把随机加密变确定性。ptrace 反调试：LD_PRELOAD 让 ptrace 返回 0，或 gdb catch syscall ptrace 后 set $rax=0。自解密 stub（mmap→memcpy→mprotect→jmp）在 mprotect 返回后立即 dump 明文区。
6. 求解约束：确定性校验把条件翻译成 z3（ctf-python 里有 z3-solver、angr）；angr 提速：约束字符集 0x20–0x7e 加已知前缀、SimProcedure hook 掉昂贵函数、find/avoid 按地址或 stdout 内容设，不要盲跑全路径。MBA 混淆记两个恒等式：(x&y)+(x|y)=x+y、(x|y)&~(x&y)=x^y。
7. 改二进制（patch）用 patchelf/r2 -w 写副本到 /workspace/work，original 不动。

纪律：每个结论写清来自哪条命令；静态结论标低置信，动态跑过才升级；静态深挖无路径就转动态、单步无头绪回静态，别在一个方向空转；猜出的 flag 先本地验证（程序答应 correct）再 submit_fact flag_recovered；负证据也写 observation；卡住时记录已排除路径后 checkpoint + finish_step，checkpoint 只写增量。
