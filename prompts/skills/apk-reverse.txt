本步是 APK 逆向。v1 镜像没有 apktool/jadx，走手工路线。以下是参考方法，按证据选择、允许跳步；已有信息无需重复获取。

1. unzip -l 看结构；把 APK 复制到 /workspace/work 再解（input/original 只读）：unzip -d work/apk app.apk。
2. AndroidManifest.xml 是二进制 XML：strings 提取包名、activity、权限、硬编码 URL/key；重点标 debuggable、allowBackup、exported=true 组件、自定义 deeplink scheme、usesCleartextTraffic——CTF 里这些指向隐藏入口。
3. classes.dex：strings -a 找 flag 格式、密钥、算法名，关键词 password|key|secret|token、Cipher/ECB、SharedPreferences、Log.d、addJavascriptInterface；方法名混淆时按字符串引用反查。
4. 分流信号：Java 层只是 JNI 包装、System.loadLibrary() 后关键逻辑消失、签名校验在 .so——命中任一立刻转 native（lib/<abi>/*.so 走 reverse-native 流程），不死磕 DEX。JNI 入口：nm -D libxxx.so | grep -i java 找 Java_com_包_类_方法（静态注册）；搜不到就找 JNI_OnLoad 里的 RegisterNatives（动态注册，函数表是方法名/签名/地址三元组）。
5. 加固识别：strings 出 libjiagu.so/com.stub.StubApp（360）、libshell（乐固）、libDexHelper（梆梆）、libexec（爱加密）、libnesec（易盾）→ 判定加壳，DEX 里没有真逻辑，改去 assets/、壳配置和 .so 找线索。
6. 跨平台框架：assets/index.android.bundle 是 React Native 明文 JS，直接 grep API/密钥/签名逻辑；Flutter 的 libapp.so 是 Dart AOT 无法反编译，以 strings 为主。
7. resources.arsc / assets/ / res/raw/ 常藏密文或二级载荷；简单校验逻辑（strcmp、Base64、固定 XOR）直接写 python 还原。

纪律：记录每个文件来源路径；找到的密文先本地解密验证再提交；负证据也写 observation；checkpoint 只写增量。
